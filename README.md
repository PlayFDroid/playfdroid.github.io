## 🎮 About PlayFDroid

PlayFDroid is a decentralized, 100% GitHub-hosted F-Droid repository dedicated to **open-source Android games**, modernized to run on modern Android versions (Android 14, 15, 16, 17+ on 64-bit ARMv9).

### Current Catalog:
- **Enigma (Revived)** – Marble-rolling puzzle game (GPLv2+)
- **Replica Island** – 2D platformer starring the Android robot (Apache-2.0)
